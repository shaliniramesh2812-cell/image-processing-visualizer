# 🖼️ Image Processing Visualizer

An interactive image processing application developed using Python, OpenCV, NumPy, Pandas, Pillow, and Streamlit.

## 🚀 Live Demo

👉 [Open Image Processing Visualizer]https://image-processing-visualizer.streamlit.app/

## 📌 Project Description

This project allows users to upload an image and apply different image processing operations.

The application converts the input image into grayscale and displays its pixel values. Users can then select an image processing operator and view the corresponding kernel, processed image, and output pixel values.

## ✨ Features

- Upload an image
- Display original image
- Convert image to grayscale
- Display grayscale pixel values
- Apply Mean Filter
- Apply Gaussian Filter
- Apply Median Filter
- Apply Sobel Operator
- Apply Laplacian Operator
- Display the selected kernel
- Display processed output image
- Display output pixel values
- Display minimum, maximum, and average pixel values

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Pandas
- Pillow
- Streamlit
